# FiscalFit Android app

A native Android shell (WebView) around your FiscalFit website.

1. Open app/src/main/res/values/strings.xml and set app_url to your Render address (https://...onrender.com).
2. Push this folder to a NEW GitHub repo (include the .github folder).
3. GitHub -> Actions -> "Build Android APK" -> open the latest run -> Artifacts -> FiscalFit-apk.
4. Unzip it, copy app-debug.apk to your phone, and install (allow "Install unknown apps").
